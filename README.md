# Hola, soy Daniel Norabuena 👋

Emprendedor. Construyo las herramientas que mi negocio necesita para funcionar mejor:
menos papel, menos Excel suelto y más datos claros para decidir.

Hoy estoy enfocado en **Casa Mamá**, un negocio gastronómico, y en llevar lo que
aprendo ahí a otros negocios reales.

## 🍲 Lo que estoy construyendo

| Proyecto | Para qué sirve |
| --- | --- |
| [**casamama**](https://github.com/Danielnora15/casamama) | App web para el registro diario del negocio, con historial y resúmenes diarios y semanales. |
| **Caja y ventas** | Cierre de caja por turno y ventas del día por medio de pago y por plato, desde el celular. Alimenta reportes en Power BI. |
| **Gastronomy Hub** | Gestión de inventario, pedidos y facturación para el negocio, con perfiles de administrador y cliente. |
